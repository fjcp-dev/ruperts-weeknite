## Shipping

Always commit, tag and push after every change — never leave a change
unshipped. Rupert plays the GitHub Pages build, so an unpushed change
takes hours to surface as "it still says the old version". Bump the
version in `index.html` (`buildTag`) and the git tag together, following
the semver rules in the README.
